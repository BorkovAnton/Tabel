# Система учёта рабочего времени

## Работа с миграциями базы данных

Для управления миграциями используется Alembic. Основные команды:

1. Создать новую миграцию (после изменения моделей):
```bash
alembic revision --autogenerate -m "описание изменений"
```

2. Применить миграции к базе данных:
```bash
alembic upgrade head
```

3. Откатить последнюю миграцию:
```bash
alembic downgrade -1
```

4. Просмотреть историю миграций:
```bash
alembic history
```

5. Просмотреть текущую версию:
```bash
alembic current
```

Перед созданием миграций убедитесь, что:
- Сервер PostgreSQL запущен
- Учетные данные в alembic.ini корректны
